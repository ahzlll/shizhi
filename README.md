# 拾知成图

把零散的提问和资料，整理成互相连接的知识网络，并按遗忘曲线在对的时间提醒回顾。

> 项目目前处于设计阶段，尚未开始编码。

## 项目简介

日常学习里，遇到不懂的就问一下 AI，问完就过去了。三个月后同一个概念又不懂，再问一遍，还是记不住。知识是一块一块的碎片，互相不认识。

拾知成图想让每一次提问都留下结构：问题整理成笔记，笔记里的知识点拆出来连成图，再按记忆规律排复习。用久了得到的不是一堆聊天记录，而是一张能看见自己学过什么的知识图谱。

## 核心功能

- **结构化笔记**：提问自动整理成含概念、要点、例子、易错点的笔记
- **知识图谱**：知识点拆成最小单位并自动建立关联。机器连得不合适的可以改，自己想到的关联也能手动补上
- **间隔复习**：按 FSRS 算法为每个知识点排复习计划，到期邮件提醒
- **检索增强**：下次问到相关问题，回答里会带出之前记过的内容以及它们之间的关系
- **手动整理**：内容重复的笔记会挂成待确认，合并、保留还是替换由你决定

## 技术栈

| 层   | 选型                                  |
| --- | ----------------------------------- |
| 语言  | Java 21                             |
| 框架  | Spring Boot 4 + Spring AI 2.0       |
| 数据库 | PostgreSQL 16 + pgvector            |
| 前端  | Vue 3 + Vite                        |
| 模型  | DeepSeek 负责对话，本地 bge-small-zh 负责向量化 |
| 部署  | Nginx + systemd                     |

## 安装

环境要求：

- JDK 21
- PostgreSQL 16，需要启用 pgvector 扩展
- Node.js 18 及以上

```bash
git clone https://github.com/ahzlll/shizhi.git
cd shizhi

# 后端
./mvnw spring-boot:run

# 前端
cd web
npm install
npm run dev
```

## 使用

计划中的主流程：

1. 注册登录，新建会话直接提问
2. 回答下方切换这条笔记的处理方式：不存 / 备用 / 过一遍 / 重点
3. 在笔记页查看、编辑，或手动关联知识点
4. 在复习页处理当天到期的卡片
